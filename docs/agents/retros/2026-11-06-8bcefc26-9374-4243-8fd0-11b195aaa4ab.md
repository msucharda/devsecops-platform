## Nálezy

### R1: Unixová větev discovery selhala až v Linux CI

- **Kategorie:** nález CI nebo review
- **Důkaz:** Ověřeno. Commit `3dd9757` opravil nález z prvního kola Copilot review. Přidal do `tools/tests/LocalCiGate.Tests.ps1` regresní test nečitelného souboru pro Unix. Blok `BeforeDiscovery` hledá program `id` přes `Get-Command -Name id -CommandType Application` a spouští `& $id.Source`. Na Linux runneru `Get-Command` vrátil dvě aplikace. Výraz `$id.Source` vrátil dvě cesty a operátor `&` je spojil do jednoho neexistujícího názvu příkazu. Výsledek: `CommandNotFoundException` a selhání discovery celého souboru. Source CI run 42239906558 selhal ve dvou jobech: `Pester (3/4)` (job 127967927698, log řádky 166–168) a `Security check mutations (1/4)` (job 127967927636). V mutačním jobu baseline kontroly `local-ci-result-binding` nenašel žádný test podle filtru (log řádky 690–692). Lokální gate na Windows tuto větev přeskočil podmínkou `$IsWindows`. Sonda na Windows s programem, který má v PATH více nálezů (`pwsh`), chybu reprodukovala (SDK záznam, události 3585–3598). Varianta se `Select-Object -First 1` uspěla (událost 3639). Oprava je jednořádkový commit `f2215bd`. Odkaz: SDK záznam, události 3158–3690.
- **Cena:** 1 další běh Source CI se 2 neúspěšnými joby. 18 volání `powershell` v hlavní session od zjištění selhání po commit opravy, včetně sledování CI (události 3158–3685). 1 opravný commit, 1 další lokální gate, 2 delta zprávy reviewerům Spec a Standards (události 3720 a 3726) a 1 další běh Source CI na `f2215bd`.
- **Navržené pravidlo:** Kód, který spouští nativní program nalezený přes `Get-Command -CommandType Application`, vybere jednu aplikaci (`Select-Object -First 1`). Implementátor, který přidá větev přeskočenou lokálním gate na Windows (`$IsWindows`), před pushem ověří stejný vzor volání s programem, který má v PATH více nálezů.

### R2: Znak mimo ASCII v testu zastavil lokální gate

- **Kategorie:** nález CI nebo review
- **Důkaz:** Ověřeno. Lokální gate spuštěný ve 14:29:29 UTC (SDK záznam, událost 2046) skončil kódem 1 v kroku `Check PowerShell` (událost 2127). PSScriptAnalyzer nahlásil pravidlo `PSUseBOMForUnicodeEncodedFile` pro `tools/tests/LocalCiGate.Tests.ps1`: soubor bez BOM obsahoval znak mimo ASCII. Příčinou byl doslovný znak `ž` v názvu testovacího souboru v nových regresních testech. Commit `3912456` nahradil znak escape sekvencí `` `u{17E} ``; soubor zůstal v ASCII. Odkaz: SDK záznam, události 2046–2239.
- **Cena:** 1 neúspěšný běh lokálního gate, 6 min 8 s od spuštění po výsledek. 3 diagnostická volání (události 2132, 2142 a 2152), 1 delegovaná oprava (událost 2172), 1 ověřovací běh (událost 2219), 1 commit (událost 2239) a 2 delta zprávy reviewerům (události 2279 a 2285).
- **Navržené pravidlo:** Implementátor zapíše znak mimo ASCII v souboru `.ps1` nebo `.psm1` escape sekvencí `` `u{…} ``. Soubor tak zůstane v ASCII a PSScriptAnalyzer nevyžaduje BOM.
